# Branding 2 (ELARA-richting)

- `woordmerk.py`: gestapeld woordmerk TIDE / TODE (Kavoon, afgerond en licht golvend, surfboard als I). `python3 woordmerk.py alles` schrijft `logo2.json` (gestapeld, liggend, board).
- `maak_font.py`: bouwt `theme/assets/tide-tode-display.woff2` (Kavoon met een rechte T).
- `illustraties.py`: handgetekende lijnillustraties (parasol, tas, golf, zon, busje).
- `stickers.py`: stickers als gevulde vorm met binnenlijnen en stickerrand.
- `brandbook.py`: bouwt `docs/brandbook/brandbook-2.html`.

Fonts: Kavoon, Courier Prime (SIL OFL), Homemade Apple (Apache 2.0). De afgeleide display-font heet bewust niet Kavoon (OFL-regel).
