# Juridische teksten

Geschreven voor Tide-Tode. Laat ze nakijken voordat de winkel echt live gaat.

| Tekst | Waar in Shopify | Template |
|---|---|---|
| Privacybeleid | Instellingen > Beleid > Privacybeleid (plak `ingevuld/privacybeleid.html`) | |
| Algemene voorwaarden | Instellingen > Beleid > Servicevoorwaarden (plak `ingevuld/algemene-voorwaarden.html`) | |
| Retourbeleid | Instellingen > Beleid > Restitutiebeleid (plak `ingevuld/retourbeleid.html`) | |
| Verzendbeleid | Instellingen > Beleid > Verzendbeleid (plak `ingevuld/verzendbeleid.html`) | |
| Herroepingsrecht en modelformulier | Online winkel > Pagina's > nieuwe pagina "Herroepingsrecht" (plak `herroepingsrecht.html` in de HTML-weergave) | `page.juridisch` |

Plak de HTML via de knop `<>` (HTML-weergave) in de editor.

In de pagina-versie (zonder `ingevuld/`) staan [EMAIL], [ADRES], [KVK] enz. Die vult het thema zelf in met de gegevens uit Thema-instellingen > Tide-Tode. Zo hoef je een adreswijziging maar op één plek aan te passen.

Verzendkosten en levertijden zijn een voorstel. Zet dezelfde bedragen in Instellingen > Verzending en levering.
