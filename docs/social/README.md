# Social media

- `profielfoto.png`: voor Instagram, TikTok, Facebook en Pinterest (Instagram maakt hem rond)
- `highlight-*.png`: covers voor de Instagram-highlights (Tassen, Onderweg, Stranddag, Zon, Info)
- `post-01` tot en met `post-09`: de eerste negen posts. Plaats ze van 09 naar 01, dan staat 01 linksboven in je raster
- `facebook-header.png`: omslagfoto voor Facebook

Bio-voorstel: *Draagtassen voor je surfboard. Board erin, tas over je schouder, handen vrij.* Met de link naar de winkel.

Opnieuw maken: `python3 tools/social/social.py && node tools/social/render.mjs`
