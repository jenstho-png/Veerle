# Instagram feed 2

Negen posts in de stijl van de webshop: dezelfde letters, kleuren, stickers en stofrondjes, en alleen eigen foto's. Elke map is één post. Upload de slides in volgorde (slide-1 eerst). `raster.jpg` laat zien hoe je profiel eruitziet. Die hoef je niet te posten.

Post van **09 naar 01**. Dan staat 01 linksboven, zoals in het raster.

Opnieuw maken: `python3 tools/social/feed2.py`

## Profiel

**Naam:** Tide Tode
**Gebruikersnaam:** tidetode (of tide.tode als die bezet is)
**Profielfoto:** `docs/social/profielfoto.png`

```
Draagtassen voor je surfboard
Board erin, tas over je schouder, handen vrij

```

**Link:** de link naar de webshop.
